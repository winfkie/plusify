# Plusify — HTML Starter

Starter frontend statis untuk prototype Plusify, berdasarkan konsep pitch deck:
- Digital premium hub / katalog terpusat
- Kategori Design, Editing, Productivity, dan AI
- Pencarian dan filter produk
- Keranjang belanja interaktif (demo)

## Cara menjalankan
1. Ekstrak folder `plusify-html-starter`.
2. Buka folder tersebut di Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan extension Live Server di VS Code.

## Struktur
- `index.html` — halaman utama
- `css/style.css` — styling dan responsive layout
- `js/app.js` — data contoh, filter, pencarian, dan keranjang demo

## Catatan penting
Ini adalah prototype frontend. Harga dan produk masih data contoh. Tombol checkout belum memproses pesanan atau pembayaran sungguhan. Untuk e-commerce produksi, perlu backend, database, autentikasi, validasi pembayaran di server, serta integrasi payment gateway. Jangan menyimpan API secret di file HTML/JavaScript.
